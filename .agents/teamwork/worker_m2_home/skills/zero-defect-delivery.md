# Zero-Defect Delivery — STRICT MODE
MANDATORY skill for EVERY coding task, bug fix, feature implementation, refactor.
Enforces zero-defect verification, blast-radius impact analysis, strict reproduction proof, clean builds, and a mandatory factual evidence block backed by real command output.

Rules:
1. Actually EXECUTED a real build, test, lint, or runtime check (never simulated or imagined), AND
2. Actually OBSERVED the real output in the current session, AND
3. Pasted that authentic output as verifiable receipts in the Mandatory Evidence Block.

Banned phrases without immediate real output: "This should fix the issue", "Everything looks good", "Seems to be working".
File reading compliance: Always use built-in tools (view_file, grep_search, find_by_name). NEVER use run_command for file I/O.
